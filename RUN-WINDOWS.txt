DEAD BABIES X — WINDOWS NATIVE PORT
Windows v1.5.1: train base extends to the bottom of the playfield.

Extract the entire ZIP into a folder, then run DeadBabiesXNative.exe.
Keep libwinpthread-1.dll and the game folder beside the executable.
Keep these four required music files beside it too:
  music3.ogg — Original
  static-reactor.ogg — Static Reactor
  acid-house.ogg — Acid House
  rock.ogg — Rock
The Music menu loads these filenames directly from the game folder.

The optional .cmd launchers have been removed. Select graphics and music in-game.
Controller: left stick moves, right stick aims, RT fires, LT alternate fire,
A collects pickups/confirms menus, RB/LB specials, Start joins/pauses.
Keyboard: A/D move, arrows aim, Space fire, Shift alternate fire,
Q/E specials, Enter confirms/joins/pauses, Escape opens the pause menu.
F11 or Alt+Enter toggles fullscreen/windowed mode.
For Steam on Linux, use the Windows executable through a compatible Proton version.

Select GRAPHICS: SUPER SUPER HD for the new cinematic art.
GRAPHICS: CARTOON retains the flat traditional-cartoon sprite pack.
ALPINE DUSK is also available with its existing full sprite pack.
Alpine Dusk now includes 109 redrawn sprite textures at 4x canvas resolution.
The existing alpine background is retained. Select the theme from Graphics.
Pause > Exit Game returns to the main menu. Main menu > Exit Game closes the app.
The original 4:3 aspect ratio and black side borders are retained.
The executable is rebuilt; four music tracks and existing graphics modes remain.
Original game/code/art: Chris Friesen and credited contributors. See notices/.
